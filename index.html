How to Install in Google Chrome (Manifest V3)

1
Open Chrome Extensions Manager
Open Google Chrome, navigate to chrome://extensions in the URL bar, and toggle Developer mode ON in the top right corner.
2
Load Unpacked Extension
Click Load unpacked in the top left corner, then select this project directory (the folder containing manifest.json).
3
Navigate to TradingView
Open any chart on tradingview.com/chart (e.g. SENSEX, AAPL, BTCUSD, etc.). Any timeframe (1m, 3m, 5m, 1h, 1D) is supported.
4
Capture & Export Data
Click the 📈 TV OHLC Extractor icon in your Chrome toolbar. Use Capture Current Candle, toggle Stream Live Data, or set a Start/End date and click Fetch & Export to Excel (CSV).
